# C++ 迴圈練習

## 作業內容
本程式使用 C++ 撰寫，練習三種迴圈的使用方式。

## 使用功能
1. 輸入姓名（name）。
2. 輸入學號（id）。
3. 輸入一個整數 n。
4. 使用 for 迴圈計算 1 到 n 的總和。
5. 使用 while 迴圈計算 1 到 n 的總和。
6. 使用 do-while 迴圈計算 1 到 n 的總和。

## 執行結果範例

```text
input name: Eric
name is Eric
input id: 1001
id is 1001
please input a number n: 10
for loop : The sum of 1 to 10 is 55
while loop : The sum of 1 to 10 is 55
do-while loop : The sum of 1 to 10 is 55
```

## 開發工具
- Visual Studio Code
- C++

## 學習目的
了解 for、while、do-while 三種迴圈的使用方式，並比較它們在計算整數總和時的執行結果。
